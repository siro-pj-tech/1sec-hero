# 1 SEC HERO — 一秒の勇者

**その一秒が、世界を救う。**

押して、ためて、1秒で離す。ひとつのボタンで剣と盾を操る、無料のブラウザゲームです。スマートフォン・PCで遊べます。

## 遊び方

1. 「冒険をはじめる」を押します。タイトルのカウンターで1秒の感覚を覚えましょう。
2. 円形ボタンを長押しし、**ちょうど1秒**を狙って離します。PCではマウスまたはSpaceキー、スマートフォンではタッチで操作できます。
3. 剣の時は攻撃、盾の時は防御です。攻撃を3回行うと防御へ切り替わります。敵を倒した場合は次のステージへ進みます。
4. PERFECTに近いほど攻撃が強く、防御で受けるダメージが減ります。PERFECT防御ならダメージはゼロ。長く押しすぎるとMISSです。
5. ステージ間のショップで「攻撃」「防御」「金銭アップ」を強化できます。各Lv1〜10、アイコンの周りのランプが現在のレベルです。
6. 全10ステージを進み、魔王を倒しましょう。クリア後はスコアとエピローグを楽しめます。

## 難易度

| 難易度 | 特徴 |
|---|---|
| ルーキー | ゲージあり。タイミング判定が広め。 |
| ベテラン | ゲージあり。1秒±0.05秒以内で命中。初期設定。 |
| ヒーロー | ベテランと同じ判定。ゲージを隠し、計測中の動きも止まります。自分の感覚だけで挑戦。 |

難易度はオプションで選び、タイトルから新しく冒険を始めると反映されます。途中の変更や敗北後の再挑戦では、進行中の難易度を維持します。

## HPと再挑戦

- ステージをクリアしてもHPは回復しません。
- HPがゼロになったら、強化と所持金を引き継ぎ、HPを全回復してステージ1から再挑戦できます。
- オプション設定はブラウザに保存されます。冒険の進行状況は保存されません。ページを閉じたり再読み込みすると最初からになります。

## オプションとスコア

BGM・SEの音量、難易度、揺れ・発光の軽減を設定できます。SEの音量変更時には確認音が鳴ります。タイトル画面ではミュージックプレイヤーで楽曲を選べます。音は最初の操作後に再生されます。

クリアスコアは「残りゴールド×PERFECT回数」を基礎に、精度・残りHP・クリアボーナスを加え、難易度・手数・挑戦回数で補正します。終了画面で内訳を確認できます。

フォルダをダウンロードし、展開した中の`index.html`をPCのChromeやEdgeで開いてください。`assets`とCSS・JavaScriptは同じ配置のままにします。インストールやアカウント登録は不要です。
